# إدارة المستخدمين

نموذج تفاعلي لنظام **إدارة المستخدمين** (ترتيب الأنظمة على البوابة)، يعمل مباشرة من المتصفح بدون أي تثبيت.

> البيانات المعروضة **وهمية** لأغراض العرض فقط.

## التشغيل

- **GitHub Pages:** من إعدادات المستودع › Pages › اختر الفرع `main` والمجلد `/ (root)` › Save. بعد دقيقة يصير النظام متاحاً على رابط المستودع.
- **محلياً:** افتح `index.html` في المتصفح.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية (لوحة المتابعة) |
| `*.dc.html` | باقي شاشات النظام |
| `dc-sources.js` | محتوى الشاشات والقائمة الجانبية والشريط العلوي |
| `dc-runtime.js` | محرك العرض الخفيف اللي يشغّل الشاشات |
| `assets/` | لوقو النظام |
